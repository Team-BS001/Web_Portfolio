# MONO — Portfolio Template

シンプルなモノトーン配色 × モーションを重視した、オリジナルのポートフォリオサイトです。
HTML / CSS / JavaScript のみ（ライブラリ不要）。

## 主な演出
- カウントアップ式ローディング → 幕が上がるトランジション
- 追従するカスタムカーソル（ホバーで拡大・反転）
- 見出しのテキストせり上がりアニメーション
- マウスに反応するパーティクル背景（Canvas）
- 無限スクロールのマーキー
- スクロール連動の横スクロール作品一覧
- スクロールフェードイン／数字カウントアップ
- 背景が塗りつぶされるサービスリスト、マグネティックボタン
- スマホ用の円形展開メニュー

## GitHub Pages で公開する
1. このフォルダの中身をリポジトリにアップロード
2. Settings → Pages → Branch を `main` / `root` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示されます

## カスタマイズ
- 色: `css/style.css` 冒頭の `:root` 変数
- 作品画像: `.card__img` の `g1`〜`g5` を `<img>` に置き換え
- 連絡先: `index.html` の `mailto:` を変更
